# QuadroFur's Game Engine!

Hey all! This is my game engine project, that I am working on during my Twitch streams (twitch.tv/QuadroFur). This is an engine designed to teach people new to programming, how to program, by handling the difficult bits, while still giving them control over everything. This is essentially just a pre-made Visual Studio project, that will allow people to follow along with my programming streams, or mess around with C++ without all the setup!

I will be adding as many features as I can, like support for top-down and isometric rendering, camera controls, etc. Most of this engine is made using SFML (https://www.sfml-dev.org/).

## Where do I start?

If you are a beginner, and you have never written code in your life, my 2 tips are to watch my Twitch streams, and learn a language like Python or even Scratch (childish, but trust me, it helps!), before an advanced language like C++. If you REALLY want to have a go, basic guides like W3 schools are also a good option, but if you catch me streaming on Twitch, bother me and ask as many questions as you wish, and try to follow along with my code! I will try to explain it as best as I can!

If you are a semi-advanced user, specifically with a slight knowledge of C++, I suggest jumping into the engine and getting something working. A square on the screen is better than nothing! From there, maybe also look at SFML documentation, and you will begin to understand HOW the engine works.

If you are a decently advanced user... Then I have no idea why you are here. If you find this cool, then thanks! If you wanna help out, best way to do it is through watching my twitch streams and pointing out when I get things wrong. I am often aware of the better way, but opt for the easier to understand way, due to the nature of the engine.

## How to run the engine:

Download the source code, specifically the zip file like any other github project, unzip the project, and load it in Visual Studio (2026+, 2022 may not work). From there, the main file you want to be working in is `main.cpp`, but feel free to mess around with any other files. It's your game engine as much as it is mine!
