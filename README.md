# QuadroFur's Game Engine!

Hey all! This is my game engine project, that I am working on during my Twitch streams (twitch.tv/QuadroFur). This is an engine designed to teach people new to programming, how to program, by handling the difficult bits, while still giving them control over everything. This is essentially just a pre-made Visual Studio project, that will allow people to follow along with my programming streams, or mess around with C++ without all the setup!

I will be adding as many features as I can, like support for top-down and isometric rendering, camera controls, etc. Most of this engine is made using SFML (https://www.sfml-dev.org/).
